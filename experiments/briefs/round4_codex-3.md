# Codex-3 4라운드: GPU 없는 채점 환경 검증 (G5)

채점 PC 사양은 모른다. GPU가 없을 수도 있다. 제출 이미지가 GPU 없이도 공식 트랙을 완주하는지 확인한다.

## 할 일
1. CPU 전용 제출 이미지(G4)에서 GPU를 숨기고 공식 트랙을 모드마다 3회 돌린다(rule, dl).
   - 기록: 완주 여부, 랩타임, Gazebo 실시간 배율(RTF), /camera/image_raw 수신 Hz, 처리 프레임률, 명령 발행률, 측정 시점 `uptime` 부하.
2. 약한 PC를 흉내 낸다. `docker run --cpus=4`와 `--cpus=8`에서 1번을 rule만 2회씩 돌린다.
3. RTF가 0.5보다 낮으면 원인을 찾는다. 카메라 렌더링, 물리, 노드 CPU 중 무엇인지 본다(`gz stats`, `top -H`, 렌더 엔진 옵션).
   - `worlds/`와 `models/` 원본은 절대 수정하지 않는다(SHA256 검사). launch 쪽 옵션만 시험한다.
4. 결과를 `experiments/results/c-bench/G5_nogpu.md`에 표로 정리하고 커밋한다. push는 하지 않는다.

## 규칙
- Gazebo 동시 실행은 최대 2개다. 다른 bench와 겹치지 않게 한다.
- 지금 호스트 부하가 약 33(16코어)이다. 부하가 높으면 그 값을 그대로 적고, 부하 10 이하에서 rule 1회를 다시 재서 비교한다.
- 시뮬레이터 시간 기준 랩타임과 벽시계 시간을 둘 다 적는다.

## 합격
- GPU 없이 rule 3/3 완주, 시뮬레이터 시간 랩타임 63–66초.
- dl도 3/3 완주하면 좋다. 실패하면 원인(프레임률, 지연)을 적는다.
